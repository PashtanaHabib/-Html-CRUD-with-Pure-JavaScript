# Pure JavaScript CRUD Operations with HTML

A simple JavaScript practice project built using HTML, CSS, and Vanilla JavaScript.

This project demonstrates CRUD operations (Create, Read, Update, Delete) through an employee management system. Users can add new employee records, view them in a table, edit existing information, and delete records.

## Live Demo

[View Live Demo](https://pashtanahabib.github.io/-Html-CRUD-with-Pure-JavaScript/)

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JavaScript)

## JavaScript Concepts Used

- **Variables (`var`):** Storing data and managing selected table rows.
- **Objects:** Organizing employee information using key-value pairs.
- **Functions:** Creating reusable blocks of code.
- **DOM Manipulation:** Accessing and modifying HTML elements.
- **getElementById():** Selecting HTML elements by their IDs.
- **getElementsByTagName():** Selecting table body elements.
- **innerHTML:** Inserting and updating table content.
- **value:** Getting and setting input field values.
- **parentElement:** Accessing parent HTML elements.
- **insertRow():** Adding new rows to the table.
- **insertCell():** Adding cells to table rows.
- **deleteRow():** Removing rows from the table.
- **Event Handling:** Using onclick events to trigger functions.
- **Conditional Statements (`if/else`):** Checking conditions and controlling program flow.
- **confirm():** Displaying a confirmation dialog before deleting a record.
- **classList.add():** Adding CSS classes to HTML elements.
- **classList.remove():** Removing CSS classes from HTML elements.
- **classList.contains():** Checking whether an element contains a specific CSS class.
- **Form Validation:** Checking required input fields before submitting data.
- **Template Literals:** Creating dynamic HTML content.

## CRUD Operations

- **Create:** Add new employee records.
- **Read:** Display employee information in a table.
- **Update:** Edit existing employee records.
- **Delete:** Remove employee records.

## Features

- Add new employee records.
- Display employee information in a table.
- Edit existing employee information.
- Delete employee records with confirmation.
- Validate required form fields.
- Reset form inputs after submission.

## Project Purpose

This project was created for practicing JavaScript fundamentals and understanding how CRUD operations work using Vanilla JavaScript and DOM manipulation without external libraries or frameworks.
